# BookRead

BookRead 是一个基于 .NET 9 和 WPF 构建的 Windows 桌面阅读器，主要用于管理和阅读本地书籍文件。

## 主要功能

- 导入 TXT、Markdown、EPUB 和 DOCX 文件并自动加入书架。
- 打开、重命名、移除书架中的书籍。
- 在文件资源管理器中定位书籍文件。
- 自动提取文本、解析章节并分页显示。
- 保存每本书的最近阅读章节和分页位置。
- 调整正文字号、行间距、阅读主题和透明背景。
- 显示或隐藏阅读页工具栏和章节面板。
- 支持全局快捷键和阅读快捷键配置。
- 支持关闭窗口后最小化到系统托盘。

## 运行环境

- Windows 10 或 Windows 11
- .NET 9 SDK

## 支持格式

| 格式 | 扩展名 |
| --- | --- |
| 纯文本 | `.txt`、`.text` |
| Markdown | `.md`、`.markdown` |
| EPUB 电子书 | `.epub` |
| Word 文档 | `.docx` |

当前版本以纯文本阅读为目标，不支持 PDF、MOBI、AZW3、DRM 电子书以及图片、字体颜色和复杂版式的还原。

## 使用说明

1. 在书架页面点击“导入本地书籍”，选择需要阅读的文件。
2. 点击书籍名称即可打开阅读页面。
3. 将鼠标移到书架条目上，可使用重命名、打开所在文件夹和移除操作。
4. 阅读页面底部工具栏可调整字号、行间距、透明背景、主题和章节面板。
5. 在设置页的“快捷键”中，可以分别配置全局快捷键和阅读快捷键。
6. 在设置页的“显示”中，可以调整阅读页工具栏和窗口关闭行为。

## 数据存储

应用数据保存在当前用户的本地应用数据目录：

```text
%LOCALAPPDATA%\BookRead\bookshelf.json
%LOCALAPPDATA%\BookRead\settings.json
```

- `bookshelf.json`：书架记录、显示名称、最近打开时间和阅读进度。
- `settings.json`：快捷键、阅读页显示和窗口行为设置。

重命名和移除操作只修改书架记录，不会修改或删除原始书籍文件。
